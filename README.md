# 🍰 00Favorite

**파일을 드래그하고, 원하는 작업을 골라 바로 실행하는 macOS 파일 도구**

이미지·영상·음원 변환부터 촬영일시 기준 파일명 정리, 이미지 합치기, 잠자기 방지까지 한곳에서 사용할 수 있습니다.

**macOS 14 이상 · Apple Silicon(M 시리즈) · 앱 버전 4.8**

> [!NOTE]
> **00Favorite은 기존 MyTangerine 프로젝트의 새 이름입니다.** Tangerine이나 Owly의 공식 제품이 아닌 독립적으로 개발한 앱입니다.

---

## ✨ 무엇을 할 수 있나요?

| 기능 | 이렇게 사용합니다 |
| --- | --- |
| 🎡 **파일 드래그 휠** | Finder에서 파일을 드래그하며 키를 누르면 작업 메뉴가 열립니다. |
| 🖼️ **파일 변환** | 이미지(JPG·PNG·WebP·HEIC·TIFF 등), 영상(MP4·MOV 등), 음원(MP3·M4A·WAV 등)을 변환합니다. 실제 선택지는 파일 형식에 따라 달라집니다. |
| 📸 **촬영일시로 이름 변경** | EXIF, Sony XML, 영상 내부 메타데이터를 확인한 뒤 촬영시각 기준으로 이름을 정리합니다. |
| 🧩 **이미지 합치기** | 여러 이미지를 세로로 연결하고 순서·간격·폭을 조절합니다. 긴 이미지를 위한 TIFF/BigTIFF 처리 기능도 포함합니다. |
| 🛠️ **편집 도구** | 사진 자르기·가리기, 압축, 메타데이터 확인, PDF 병합 등의 작업을 실행합니다. |
| 📁 **Finder 작업** | 경로 복사, 원본 위치 표시, 사본 만들기, AirDrop, 터미널 열기 등을 제공합니다. |
| 🦉 **잠자기 방지** | 다른 앱을 사용하면서도 단축키로 ON/OFF할 수 있습니다. 화면도 함께 유지하는 단일 모드로 정리 중입니다. |

> [!IMPORTANT]
> 촬영일시가 불명확한 파일은 시간을 임의로 추측하지 않습니다. 사용자가 근거와 시간대를 확인한 후 이름을 변경합니다.

## 🚀 처음 사용하는 방법

**1. 설치**

1. [GitHub Actions 빌드 목록](https://github.com/yespick0402/00Favorite/actions)에서 **성공한 최신 빌드**를 엽니다.
2. 아래쪽 **Artifacts**에서 `00Favorite`이 포함된 Mac ARM64 파일을 내려받아 압축을 풉니다. (GitHub 로그인이 필요할 수 있습니다.)
3. `00Favorite.app`을 Mac의 **응용 프로그램** 폴더로 옮겨 실행합니다.
4. 첫 실행에서 필요한 권한 안내가 나오면 아래 **권한 설정**을 참고하세요.

> 이 저장소는 현재 GitHub Actions로 macOS용 앱을 빌드합니다. 자동 업데이트 및 Apple 공증 배포를 제공한다고 가정하지 마세요. 출처를 확인한 빌드만 설치하세요.

**2. Finder에서 파일 드래그**

파일을 클릭한 상태로 끌어 움직이다가 아래 키를 누르면 작업 휠이 열립니다. 휠에서 원하는 항목을 선택해 실행하세요.

| 키 | 메뉴 | 대표 작업 |
| --- | --- | --- |
| `⇧ Shift` | **CONVERT** | 이미지·영상·음원 형식 변환 |
| `⇧ Shift + ⌘ Command` | **화질 옵션** | 변환 품질을 지정해 실행 |
| `⌥ Option + ⇧ Shift` | **TOOLS** | 자르기, 압축, 촬영일시 확인, 메타데이터 |
| `⌃ Control` | **ACTIONS** | 이름 변경, 경로 복사, Finder 작업, 이미지 합치기 |

*기본 단축키이며 설정에서 변경할 수 있습니다. Finder 드래그를 가로채지 않도록 안전 모드를 사용합니다.*

**3. 잠자기 방지**

메뉴 막대의 케이크 아이콘에서 잠자기 방지를 켜거나 끕니다. 기본 전역 단축키는 **`⌃ Control + ⌥ Option + .`** 입니다.

- Finder, 브라우저 등 다른 앱을 사용하는 중에도 동작합니다.
- 단축키를 눌러도 다른 앱의 입력창에 마침표가 입력되지 않도록 macOS 전역 단축키로 등록합니다.
- 켜짐/꺼짐 상태는 메뉴 막대 케이크 아이콘으로 표시합니다.
- **'Mac과 화면 모두 켜두기' 단일 모드**는 SCREEN1 변경분의 최종 실사용 검증을 진행 중입니다.

## 📷 촬영일시 이름 변경, 무엇이 다른가요?

예를 들어 `C0313.MP4`와 함께 촬영된 Sony XML이 있다면, 프로그램은 XML의 촬영일시를 우선 확인합니다.

```text
변경 전  C0313.MP4
변경 후  20261110_102819_C0313.MP4
```

- **근거 확인:** 사진은 EXIF, Sony 영상은 동반 XML, 그 밖의 영상은 내부 날짜 등 파일에 맞는 정보 확인
- **시간대 확인:** UTC인지 현지시각인지 애매하면 **검토 필요**로 표시
- **원본 보호:** 이름 변경 전 메타데이터 재확인, 충돌하는 파일명 방지, 영상과 연관된 XML 함께 처리
- **실제 검증:** ExifTool 실행, Sony MP4/XML 이름 변경, 파일 내용 SHA-256 보존 테스트 통과

사진·영상 형식에 따라 메타데이터가 다르며, 촬영일시가 항상 존재하는 것은 아닙니다.

## 🔐 필요한 macOS 권한

| 항목 | 필요한 이유 |
| --- | --- |
| **입력 모니터링** | Finder에서 드래그 중 Shift·Control 등 입력을 감지합니다. |
| **기기 제어 및 데이터 접근 / 손쉬운 사용** | macOS 버전에 따라 이름이 다르게 표시됩니다. 상태를 확인하되 모든 환경에서 무조건 요청하지는 않습니다. |
| **파일·폴더 접근** | 사용자가 선택한 바탕화면·문서·다운로드·외장 드라이브 파일을 처리할 때 macOS가 허용을 요청할 수 있습니다. |

권한이 부족하면 00Favorite이 안내 창을 표시합니다. **권한을 승인한 뒤에는 앱을 완전히 종료하고 다시 실행**해 주세요. Mac의 `시스템 설정 → 개인정보 보호 및 보안`에서 해당 항목을 확인할 수 있습니다.

## ❓ 문제가 생겼다면

**파일을 드래그해도 휠이 안 떠요.** 입력 모니터링 권한과 앱 재실행 여부를 먼저 확인하세요. Finder에서 파일 드래그를 시작해야 합니다.

**영상 이름 변경에 ‘확인 필요’가 떠요.** 파일 자체의 시간대가 불명확하다는 뜻일 수 있습니다. 촬영 당시 실제 시각과 카메라의 시간대 설정을 확인한 뒤 선택하세요.

**파일 변환 결과가 다르게 보여요.** 출력 형식과 화질 설정을 확인하세요. 손실 압축 형식은 최고 품질로 저장해도 원본과 비트 단위로 동일하지 않을 수 있습니다.

**개발 관련 오류가 발생했나요?** [GitHub Issues](https://github.com/yespick0402/00Favorite/issues)에 사용한 빌드 식별자, macOS 버전, 재현 방법, 오류 로그를 남기면 문제를 구분하는 데 도움이 됩니다. 파일 내용이나 개인정보는 첨부 전에 가려 주세요.
